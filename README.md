## Featured Projects

* **[Kiln Studio](https://github.com/Httpslakshya/KILN-Studio)** — A unified AI content platform merging PDF RAG (Qdrant), live multi-domain fact-checking, and an autonomous 4-agent content pipeline (Researcher → Verifier → Writer → Editor) that turns one verified draft into an article, LinkedIn post, carousel deck, and reel script — plus the AgentPrahari guardrail console, all in one product.
* **[AgentPrahari](https://github.com/Httpslakshya/AgentPrahari)** — A comprehensive, pip-installable guardrail layer for AI agents/LLMs. Regex + LLM-as-judge detection, `shield.wrap()` quickstart, FastAPI/Flask middleware, native LangChain & CrewAI integrations, and a CLI. **Published on PyPI** as `agentprahari`.
* **[Cosmo](https://github.com/Httpslakshya/COSMO-AI)** — Voice-activated multi-agent desktop assistant for Windows. Multi-agent architecture (Supervisor/Router → Planner → Executor → Critic/Verifier) built with LangGraph, hybrid-search long-term memory via Chroma Cloud, and a unified LLM gateway (Groq primary, OpenRouter/Gemini fallback) with sub-250ms speech-to-text.
